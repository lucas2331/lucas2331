### 👨‍💻 About me

I'm a full-stack developer focused on **internal business systems** — from React interfaces and Node.js/Express APIs to **TOTVS RM integrations**, SQL Server reporting and deployment on Windows Server + IIS.

Most of my work runs behind a corporate firewall: approval workflows, document and contract management, NF-e/XML integration monitoring and management dashboards displayed on TVs.
