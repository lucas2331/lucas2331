### Hi, I'm Lucas 👋

Full-stack developer working on **internal business systems**: React front ends over
Node.js/Express APIs, talking to an **ERP (TOTVS RM / SQL Server)**, deployed on
Windows Server + IIS.

Most of what I ship lives behind a corporate firewall — approval workflows, document and
contract management, NF-e/XML integration monitoring and TV dashboards for management —
so the contribution graph below is a poor proxy for what I actually build. 🙂

**What I'm working on:** a family of `portal-*` apps — Express APIs + React SPAs published
as IIS sub-applications, with SOAP authentication against TOTVS, JWT sessions, SQL Server
reporting queries and PowerShell deploy pipelines.
